# SIH26163 — Submission Notes

## Project summary

An authorized, evidence-driven security assessment of the **self-hosted** World
Monitor deployment, delivered as a self-contained toolkit under `assessment/`.
It implements the full workflow DISCOVER → ANALYZE → DETECT → SAFE-VALIDATE →
COLLECT-EVIDENCE → ASSESS-RISK → REMEDIATE → RE-TEST → REPORT around one confirmed,
remediated, re-tested finding (**F1**) plus two documented recommendations.

## Architecture summary

Plain-Node toolkit (no extra dependencies): `engine/` (discovery, CVSS v3.1,
evidence collector, report generator), `poc/` (BEFORE/AFTER controlled PoC),
`tests/` (9-case F1 regression suite), `data/` (findings + generated evidence +
assessment JSON), `dashboard/` (security console UI), `reports/` (MD/HTML),
`docs/`. The only change to the target app is the F1 remediation in
`src-tauri/sidecar/local-api-server.mjs`. Original behavior preserved on tag
`BASELINE-SIH26163`.

## F1 summary

Self-hosted Docker RSS proxy egress-control gap: the sidecar `/api/rss-proxy` route
lacked the destination-domain allowlist and 5 MB response cap that the hosted
`api/rss-proxy.js` enforces, and the Docker ingress injects the transport token on
every caller. Result: an authenticated open-web-proxy + memory-amplification gap on
self-hosted instances. **CVSS v3.1: 7.5 (High)** primary / 5.3 (Medium) conservative
(computed by `assessment/engine/cvss.mjs`, not invented). Confidence: High
(separate from severity).

## Evidence summary

Generated by executing the checks (not hardcoded), stored in
`assessment/data/evidence.json`:

- **E-F1-01** BEFORE/AFTER PoC — BEFORE: non-allowlisted host fetched, ~64 MB body,
  ~327 MB process RSS growth. AFTER: HTTP 403 before any outbound request, ~0 MB.
- **E-F1-02** regression suite — **9/9 PASS**.
- **E-F1-03** SHA-256 digests of the remediated route + hosted reference.

## Remediation summary

`src-tauri/sidecar/local-api-server.mjs`: domain allowlist
(`WM_RSS_ALLOWED_DOMAINS`, www-tolerant, default-deny), per-hop redirect
re-validation, and a 5 MB `maxResponseBytes` stream-abort cap in `fetchWithTimeout`.
SSRF guard, address pinning, and legitimate feed behavior preserved.

## Re-test summary

`node --test assessment/tests/f1-rss-proxy.security.test.mjs` → 9/9 PASS.
`node assessment/poc/f1-rss-proxy-poc.mjs` → BEFORE 200/64 MB vs AFTER 403/aborted.
Existing sidecar suite: 92 pass / 2 pre-existing baseline failures (unrelated,
verified by stashing the fix and re-running the baseline).
